# Modern Tic-Tac-Toe

A polished, modern take on classic tic-tac-toe, built with React, Vite, and
Tailwind — a learning/portfolio project pairing UI polish with a real
minimax AI opponent.

## Scope (v1)

- Classic 3x3 tic-tac-toe
- vs-AI mode with a perfect-play (minimax) opponent — unbeatable
- Local 2-player pass-and-play mode
- Modern, animated, responsive UI (likely dark mode)
- Deployed to GitHub Pages with a shareable link
